# Prospecto — packs de prospection

Version 2026-10-30-paris-extrait-v3, données du 2026-10-29. 50 établissements publics réels répartis sur 1 département(s).

Les fichiers se téléchargent dans Prospecto puis se consultent localement. Aucune API ni ordinateur personnel ne doit rester démarré pour les servir.

La couverture de chaque territoire est indiquée dans son catalogue. Un extrait partiel ne représente pas le département entier. Cette publication ne contient aucune observation énergétique, donnée de CRM privé, base de travail ou code de l’application Flutter.
